# Rushikesh Gadekar — Portfolio

A responsive React + Vite portfolio with a hybrid design: a dark, cloud-inspired hero and clean project/content sections.

## Run locally

1. Install Node.js (LTS) if it is not already installed: https://nodejs.org/
2. Open Terminal in this folder.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy free with Vercel

1. Create a GitHub repository and upload this project's files.
2. Sign in to https://vercel.com/ with GitHub and import the repository.
3. Keep the framework preset as Vite. Build command: `npm run build`. Output directory: `dist`.
4. Click Deploy. Vercel will provide a public `.vercel.app` address.

## Before submitting

- Check every section on mobile and desktop.
- Confirm the resume download works.
- Add your real GitHub repository URLs to project cards if available; the cards currently describe projects but do not claim live demos.
- The Cloud & CI/CD Lab card is deliberately worded as coursework/learning. Edit it to reflect only the tools and steps you actually completed. The `*` note can be removed after you update it.
- Verify all personal details and links before sharing the public site.

The website is a static frontend; no backend or paid domain is required.
